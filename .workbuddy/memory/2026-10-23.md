## 修了什么（commit 517defa，12 文件 +329/-62）

1. **AppMeta 版本漂移（🔴 红灯包根因）**：`common/AppMeta.ets` 还是 1.0.2/1000003，
   与 app.json5 的 1.0.3/1000004 脱节 ⇒ 1.0.3 包里「关于」显示 1.0.2，
   守漂移的 smoke 测试因此红灯（上轮 122/123 带着红灯出的包）。已同步，测试回绿。
   **教训**：smoke 机制是 work 的，缺的是出包前看一眼测试报告的人——
   出包流程必须加一步 `npm test | grep -E "^# (pass|fail)"`。
2. **importAll O(N²)（🔴）**：旧实现逐篇调 saveEntry，每篇结尾 saveIndex 全量重写
   +加密+原子写整个索引 ⇒ N 篇 = N 次全量写。改为「决策/IO 分离」：
   - `planImport(existing, items, now)` 纯函数落 `data/BackupService.ets`
     （id 分配/撞号换号/胶囊封存/非法 date 跳过/now 注入），语义进 CI；
   - `NoteStore.importAll` = planImport → 逐篇 `writeEntryBody`（只写正文密文）
     → `sortEntries(concat)` → **一次** saveIndex；落盘失败回滚内存索引，返回 -1
     （调用方 Settings.ets 据此出失败 toast；孤儿正文无害，下次导入按 id 重写）。
3. **备份文案谎报（🟡）**：`daysSinceMs` 旧把「从未备份」和「时间异常」都返回 -1，
   设置页于是把「系统时间被改过」显示成「还从未备份过」。拆出 -2，文案三分支。
4. **注释失真三处**：Editor 保存脉冲注释写 spring 实际 `Curve.EaseOut` 220ms；
   Index 骨架注释写「300ms bootstrap」实际 loaded 同步置 true（无该延时）；
   （第三处备份文案即上条，属行为失真）。
5. **门面**：私记 README 版本/用例数过时；reader README 177→182、M6 补 1.0.4、
   字体「可选下载」改规划口径（无入口，上线需连带 INTERNET 权限+隐私政策+商店文案）；
   菊座风文档 115KB→3.4MB、57→182、功能列表补 1.0.4 四件。
