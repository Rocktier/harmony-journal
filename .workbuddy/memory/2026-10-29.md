## 五、顺带修一个两仓不一致：本仓的记忆从来没进过 git

**发现**：本仓 `.gitignore` 第 50 行是 `.workbuddy/`（整目录排除）⇒
**本仓的所有记忆日志（10-19 / 10-23 / 10-26）一直是「只在本机」状态，从未进过版本库**。
而 RockReader 仓**没有**这条规则，`.workbuddy/memory/` 19 个文件全部被追踪。

⇒ 意味着：**本仓的台账在换机器/换人时会丢**，而 Reader 仓的不会。

**处理**：把规则改成只放行 memory/：

```
.workbuddy/*
!.workbuddy/memory/
```

（`find .workbuddy -type f` 确认过本仓该目录下**只有日志、没有缓存/会话状态**，
所以放行是安全的；将来 `.workbuddy` 下若长出别的东西仍会自动排除。）

⇒ **本次一并把 5 个历史日志文件纳入版本库**（10-19 / 10-23 / 10-26 / 10-28 / 10-29）。
**两仓行为已统一。**
