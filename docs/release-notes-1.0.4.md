## 给审核员的要点（自己看，不粘进正文）

- **零权限**：`module.json5` 未声明任何权限，无网络请求、无账号体系。
- **统计口径**：`computeStats` / `monthlyWords` / `moodCounts` 全部从本机内存索引现算
  （零 IO、零联网）；未到期时间胶囊的字数是**显式过滤**的——「本月 800 字」
  不能剧透「锁着的那封信写了多长」，这条纪律有单测锁着
  （`test/stats.test.ts`：「未到期胶囊的字数不计入（防剧透）」）。
- **跟随系统**：换色板走 AppStorage 换对象，运行中不调 `setColorMode`
  （那会重建 UIContent、页面栈保不住，2026-10-16 实测过）。
- **本次修的六个 bug 全部有 dumpLayout / 实拍定位**，不是推测：
  1. 列表不刷新 —— `noteRowKey` 原为 `'n:'+id`，key 不含「内容变了」的信号，
     LazyForEach 不重建 item；现带 `updatedAt + words`。
  2. 柱状图只渲染 1 个月 —— item Column 无确定宽度，`width('100%')` 百分比
     循环回退到 Row 全宽，12 个月并排每个占满行宽，只有第 0 个月在屏内。
  3. 筛选 chip 高亮 —— 选中态原为 `#E3E6E8` vs `#FFFFFF`（浅灰 vs 白），真机看不出。
  4. 标签要点两次 —— chip 的 ForEach key 不含选中态。
  5. 跟随系统无变化 —— `isDarkMode('system')` 返回 null ⇒ 色板恒浅色。
  6. 主密码页间距 —— Scroll 内 Column 高度=内容高，`Blank()` 永远 0 高。
- **测试**：`npm test` 136/136（新增 5 条：`resolveDark` 守门、
  「改文字/改字数 ⇒ key 必变」守门，外加统计页既有覆盖）。
