# ── P1-8 序列化字段白名单（2026-10-22 补）────────────────────────────
# 落盘 JSON（索引 index.json / 单篇日记 blocks / 加密备份）全部是
# JSON.stringify(holder) → 字段名写进文件。属性混淆会同步重命名
# interface 与对象字面量的属性名：同版本自洽，但**跨版本混淆名会变** ——
# 旧版写盘的字段名（如 mfa）新版按新名读不到，用户的日记元数据会静默清空。
# 白名单把这些字段名钉死为明文，「十年可读」承诺才成立。
#
# ⚠️ 待模拟器验证（2026-10-22 记）：已上架的 1.0.2 是否已带混淆名写盘 ——
#    拉一份真实 index.json 看字段名即可判定。若已是混淆名，下个版本
#    必须附带「旧混淆名 → 明文名」迁移映射，否则升级即丢元数据。
